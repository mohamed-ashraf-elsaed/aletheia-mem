8. Findings

Facts found while reverse engineering claude-mem 15.2.0, deliberate differences in the clone, and what is not verified. Each finding says how it was established.

8.1 Defects in the original

F1. The observation half of My Work is empty on a current database. The query that loads observations selects observations.content_session_id. That column does not exist in this database's observations table (its CREATE TABLE was read from sqlite_master; the column is not there). SQLite throws no such column: content_session_id. The reader's helper treats "no such column" as "empty result", so the page shows coverage.observations: 0 and agents: [] even with 401 observations in the database. Established by running the same SELECT against the live database (error reproduced) and by the live /api/work-view returning 0 observations and 0 agents. Clone behaviour: by default derives the column from sdk_sessions and shows agents and activity. ALETHEIA_BUG_COMPAT=1 reproduces the original. The differential test runs in that mode.

**F2. Repository detection from git push output misses SSH remotes.** Git prints To github.com:org/repo.git (it hides git@). The original's parser accepts only https://github.com/.., git@github.com:.. and ssh://git@github.com/.., so commits and branches pushed over SSH have no repo and no GitHub link unless another source supplies it. Established from the parser code and reproduced in test/readmodel.test.mjs. Kept as is (faithful).

**F3. MY-RULES.md header names the wrong port.** It says "(localhost:37777)". The worker's port is 37700 + (uid % 100) (see save_goals.py, worker_base_url), 37700 here. Cosmetic. The clone writes its own URL.

F4. A wrong column name is silent everywhere. The safeAll-style helper hides schema mismatches in every query, which is how F1 survived. The clone keeps that behaviour for compatibility but F1 shows the risk; a debug log on swallowed errors would have caught it.

8.4 Observed side effect worth knowing

On this machine the original's auto-refresh was already running while this work was done: its refresh.json shows agent: claude-code, steps grouping, review, alignment, story, and its goals list is built from the owner's typed prompts. The page you see at :37700 is therefore backed by an LLM reading your agent history, automatically, every 10 minutes when something is due.
