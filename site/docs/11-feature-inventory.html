11. Feature inventory: claude-mem vs this project

Source: a shallow clone of https://github.com/thedotmack/claude-mem at commit abd9aaa (2026-10-25, version 15.2.0): 160 000 lines of TypeScript under src/, plus docs/, plugin/, skills/. Every row below names where it lives in the repo. Status is this project, today:

  • Done: same behaviour, tested.
  • Partial: a working version with named differences.
  • Missing: not built.
  • Out of scope: paid, cloud, or meaningless without the vendor's account system.

11.1 Corrections to common assumptions

AssumptionWhat the repo says
"The repo is paid."The code is Apache-2.0 (LICENSE, docs/license.md). Memory engine, server, CLI, SDKs, adapters, MCP tools, schemas, reference knowledge agents are open. Paid or reserved (docs/ip-boundary.md): hosted cloud ("Magic Recall"), team/org sync, admin dashboard, SSO/SAML/SCIM, enterprise RBAC and audit UI, DLP, premium knowledge agents, managed evals, support. The README's "CMEM Pro" is hosted memory processing with a 30-day free trial; without it memory falls back to your own Anthropic plan.
"It only works with Claude."It already ships installers or adapters for Claude Code, Codex CLI, Cursor, Windsurf, Gemini CLI / Antigravity, Kimi, OpenCode, Pi, Hermes, OpenClaw, OMP, DeepSeek harness, T3 Code and Grok bot (src/services/integrations/, src/cli/adapters/). "Works with any tool" is therefore not a differentiator by itself. See 12 for what is.
"It has no telemetry."It has: anonymous events to PostHog, on by default (opt-out), off with DO_NOT_TRACK or CLAUDE_MEM_TELEMETRY=0 (src/services/telemetry/consent.ts).

11.11 Honest summary

Roughly: My Work is complete; the memory engine is a small, correct core; and the parts that make the original "fully managed" (vector search, observer pipeline with routing, per-tool installers, settings UI, viewer session pages, smart file read, knowledge agents, modes) are not built. 12 orders them by value.
