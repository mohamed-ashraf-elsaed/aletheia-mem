28 — Competitor report

Date: 2026-10-26. Every number is labelled measured-by-us, vendor-claimed, third-party or peer-reviewed. Where two numbers come from different conditions they are never put in one comparison as if equal. Machine-readable rows: 28-competitor-report.json (313 rows copied from the research tables).

1. Summary

  • 93 products tracked. 42 from 21 plus 51 new ones in research/A3-new-competitors.md. Groups: coding-agent plugins, memory SDKs and layers, graph memory, MCP servers, rules-sync tools, IDE and chat built-in memory, research systems.
  • The closest product is claude-mem (103k stars, Apache-2.0). It has 9 first-party harness installers, a background observer, 35 mode files, 32 translated READMEs and a paid cloud tier at $30 to $100 a month.
  • What we have today, proven: local SQLite with FTS5, hybrid retrieval, an MCP server, REST, CLI, rules sync into nine tool formats, automatic capture for Claude Code (smoke-tested on the owner's machine) and Command Code (recorded payloads only), fact extraction with validation, a crash-safe queue, contradiction handling, dedupe and importance scoring.
  • What we do not have: answer-accuracy measurements, sync, team mode, graph retrieval in production, installers for most tools, Windows and macOS tests, a translated README, a published package.
  • The one place the claim is already measured: retrieval on LoCoMo against claude-mem, same dataset and questions (section 4). Everything else in section 9 is a goal.

2. Method

Found by: GitHub topic and keyword search, npm and PyPI metadata, Hacker News "Show HN", awesome-lists, the vendors' own pricing and docs pages, benchmark papers. Included if the product stores memory, rules or context for AI agents and had a readable public page. Not covered: Reddit (not reachable by search in this run), closed products with no public page, products found only after the run. Each row's source and fetch date are in the research files; blocked pages are listed as UNVERIFIED there. Stars and last-commit values came from gh api on 2026-10-26; "last commit" can be pushed_at, which differs from the default branch's last commit by 1 to 2 days (A3 section 9).

4.2 Published numbers from others (A3-benchmarks.md, 94 rows)

These are mostly answer accuracy from the vendors themselves. They cannot be compared with section 4.1 because the metric, reader model and judge differ. A3 shows each with dataset, model, who ran it and a URL. Conflicts shown, not resolved:

  • mem0 on LoCoMo: between about 20 (a user rerun) and 92.5 (mem0's own current claim), with 66.9 to 71.4 in several papers.
  • Zep on LoCoMo: 58.4 to 94.7 depending on who ran it and when.
  • Supermemory on LongMemEval-S, gpt-4o: 97% on its page versus 81.6% on Mastra's page updated 2026-02-17.
  • MemPalace: 96.6% Recall@5 reproduces as a retrieval figure, but end-to-end accuracy with gpt-4o-mini is 0.668. A 0.826 figure was retracted.
  • EverMemOS: 93.0% claimed versus 52.2% and 38.4% in a user rerun; the maintainer closed the issue without a new result.
  • LoCoMo itself: one audit post reports 99 errors in 1,540 questions; its repository was not read, so the counts are unchecked.

10. Positioning

Three niches where free, tool-neutral, reproducibly benchmarked memory can win:

  1. People who use more than one AI coding tool. One memory and one rules file for all of them. No memory product syncs rules, and no rules tool stores memory.
  2. Teams and individuals who will not pay or send data out. Everything a paid tier sells (sync, hosted extraction, remote MCP, team mode) self-hosted and free, per docs/27.
  3. People who distrust vendor benchmarks. Published commands, raw outputs, and a policy of labelling vendor claims as vendor claims.

One-paragraph pitch (usable only for what exists today): "Aletheia is a free, local memory and rules hub for AI coding tools. It captures your sessions in Claude Code, remembers what matters, and keeps your rules in sync across tools, with benchmarks you can re-run yourself."

Do not claim: "works with" any tool without a real-install test; any answer-accuracy number; any "beats everyone" line; sync or team features; stars or downloads.
