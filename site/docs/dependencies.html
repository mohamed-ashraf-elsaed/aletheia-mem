Dependencies

Aletheia has no required runtime dependencies. It uses the Bun standard library and Bun's built-in SQLite binding only. The audit that enforces this is scripts/audit-deps.mjs:

bun scripts/audit-deps.mjs

The command fails when a required dependency is added without a written reason in the script's allowlist, or when a listed licence is copyleft. Run it in CI and before a release.

devDependencies

None. The project has no build step and no test-only packages; the test suite runs with bun test alone.
