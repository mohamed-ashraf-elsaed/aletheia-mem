claude-mem alternative: Aletheia compared with claude-mem

Aletheia (aletheia-mem) is a free, local memory and rules hub for AI coding tools, and a possible claude-mem alternative if you want one store shared by several hosts. This page compares it with claude-mem, the larger and older project, and says where each one is ahead. Aletheia is not affiliated with or endorsed by the claude-mem authors or Anthropic.

Short answer

claude-mem is the bigger, more mature project. It has a far larger community, more features and more integrations. Choose it if Claude Code is your main host and you want its live viewer, its file read gate, its cloud sync option or its community.

Aletheia is a small alpha project. Choose it if you want one SQLite store that several hosts read over MCP, REST or the CLI, rules written once and synced into each host's own instruction file, and facts that record when they were true. Both projects run on your machine and both are Apache-2.0.

The two can run side by side. You can also copy your claude-mem memories into Aletheia.

Where claude-mem is ahead

Every item below is stated in claude-mem's documentation. Items keep the fetch date shown on them. Items dated 2026-10-29 were not fetched again on 2026-11-11, so check them against the current docs. Aletheia's status for the same item is in the second half of each line.

  • Community and maturity. The numbers above are claude-mem's. Aletheia's repository is days old and has one maintainer. Its real-tool evidence comes from one user on one machine. See Status and limits.
  • A live viewer. claude-mem's "My Work" page runs at the local worker URL, usually http://localhost:37777. It gathers recorded requests, progress and finished results and reads the saved memory database. Source: https://docs.claude-mem.ai/usage/my-work.md, 2026-10-29. Aletheia has its own web interface, described in The dashboard. It is newer and has had less use.
  • A file read gate. claude-mem blocks Claude Code from reading a whole code file of at least 32 KB when that file already has observations, and offers an outline or a line range instead. It is on by default and fails open. Source: https://docs.claude-mem.ai/file-read-gate.md, 2026-10-29. Aletheia has the same kind of gate: a Claude Code PreToolUse hook for Read calls src/hub/smart-file.mjs and denies a whole-file read of a file of at least 32 KB that has memories, with an outline and a request to read a line range. It is off by default (dashboard setting readGate.enabled), fails open, and is covered by tests (test/file-gate-hook.test.mjs); it has not been run in a long real Claude Code session. The file_outline MCP tool returns the outline for any client.
  • Many integrations. The installation page lists Claude Code, Cursor, Windsurf, OpenCode, Codex CLI, Antigravity CLI and OpenClaw, and the README adds T3 Code, Pi and DeepSeek Harness. Sources: https://docs.claude-mem.ai/installation.md and https://github.com/thedotmack/claude-mem, 2026-10-29. On 2026-11-11 it also lists Devin and, as search-only hosts, Copilot CLI, Goose, Roo Code and Warp (sources in the facts above). Aletheia has hook adapters for six hosts and MCP plus rules for a seventh. Hooks ran in real sessions of Claude Code (two days of use), Command Code (one short session) and Codex CLI (one interactive session), one user on one machine. See Tools overview.
  • Cloud sync. claude-mem offers an optional, paid cloud sync through cmem.ai Pro. It replicates the memory database across your devices. Its docs warn that observation narratives and full prompt text go to the sync hub. Source: https://docs.claude-mem.ai/cloud-sync.md, 2026-10-29. Aletheia Sync is self-hosted and free, and it has only been tested on loopback. See Sync.
  • Vector search. claude-mem's search tool matches by meaning first and then by keywords when its Chroma vector index is running. Source: https://docs.claude-mem.ai/usage/search-tools.md, 2026-10-29. In Aletheia, vectors need the optional @huggingface/transformers package. Without it, search is keyword search (SQLite FTS5). With it and stored vectors, search on MCP, REST and the dashboard also ranks by embeddings and fuses both lists, and says in a note when the dense channel did not run. A query with Chinese, Japanese or Korean text also runs a CJK channel. See Search.
  • More features around memory. Its introduction page lists knowledge agents, a mode system, 28 languages and folder context files. Source: https://docs.claude-mem.ai/introduction, 2026-10-29. The README also lists TeamBrain, a shared workspace. Source: https://github.com/thedotmack/claude-mem, 2026-10-29. Aletheia has some counterparts, such as modes, an output-language setting and a self-hosted team mode (Team mode). For folder context files, Aletheia has an explicit command, aletheia folder-context <dir> --write (CLI reference). It is a dry run by default, it writes only a managed block, and nothing runs it automatically: no hook, server route or installer calls it. This page does not claim parity with any of them.

Where Aletheia differs

Each point is backed by Aletheia's code or README.

  • A tool-neutral store. One SQLite store holds memories from every host, tagged with the host name. Any host reads it over MCP (stdio and HTTP), a REST API under /v1 or the CLI. Source: the interfaces table in the README.
  • Rules sync to many instruction files. You write a rule once. aletheia rules sync writes it into the instruction file of each host in the registry, for example CLAUDE.md, AGENTS.md, GEMINI.md, a Cursor .mdc file and a Windsurf rules file. The registry has ten entries ([src/hub/tools.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/hub/tools.mjs)). Your own text outside the managed block is left alone ([src/hub/rules-sync.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/hub/rules-sync.mjs)). claude-mem also writes CLAUDE.md files, but its docs describe them as folder context with activity timelines, not as rules you author. See Rules.
  • MCP, REST and CLI. The MCP server lists 14 core tools, plus two read-only team tools (team_brief, team_search) when the caller belongs to a team. They are in MCP tools (TOOL_DEFS and TEAM_TOOL_DEFS in src/hub/mcp-tools.mjs). The REST API and the CLI cover the same store. claude-mem lists 26 tool definitions, two of them team tools (facts above), so it has more tools.
  • Local backups. aletheia backup run|list|status and aletheia restore <snapshot> snapshot hub.db to <data dir>/backups/; scheduled backups are off by default (backup.enabled). claude-mem has local backups too (release 15.3.0, above), so this is not a difference in kind. See Backup, export and import.
  • Chinese, Japanese and Korean search. A query with CJK text also runs a CJK channel, fused with the keyword list. See Search. I did not test claude-mem on CJK text, so no comparison is claimed.
  • Facts with two time axes. A fact stores when it was valid (valid_from_epoch, valid_to_epoch) and when the hub recorded or expired it (recorded_at_epoch, expired_at_epoch). The fact_history tool answers "what was true on this date" with its as_of argument. Sources: [src/hub/store.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/hub/store.mjs) and [src/hub/mcp-tools.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/hub/mcp-tools.mjs). See Facts and contradictions.
  • A benchmark gate. CI fails a change that loses more than one point of Recall@5 on a seeded synthetic corpus ([bench/gate.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/bench/gate.mjs), workflow). It runs on Linux only. See Benchmarks.
  • Loopback only by default. The server binds 127.0.0.1 unless you set ALETHEIA_HOST. A non-loopback bind turns on a login ([src/config.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/config.mjs), [src/server.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/server.mjs)).
  • No telemetry. The README states there is no account, no telemetry and no network call unless you configure a model provider. A text search of src/ and bin/ for telemetry, analytics, PostHog and Sentry finds only a comment that says "No telemetry". claude-mem's docs say its anonymous usage analytics are on by default and can be turned off with npx claude-mem telemetry disable. Source: https://docs.claude-mem.ai/telemetry.md, 2026-10-29. The 2026-11-11 docs dump says the same and adds that DO_NOT_TRACK is honoured (https://docs.claude-mem.ai/llms-full.txt, 2026-11-11).

Measured numbers

Retrieval only. The numbers show whether the evidence for a question is in the top five results. They are not answer accuracy, and answer accuracy is not measured.

On the LoCoMo dataset, 1,536 questions with gold evidence, raw dialogue turns stored as memories:

claude-mem 15.2.0, as shippednot recordedChroma on or off not recorded; raw output not committed36.0%0.285p50 1,699 ms, p95 2,824 ms (idle, 40 queries)

Aletheia, keyword search (BM25)2026-10-26in-process, no vectors55.3%0.4822.00 ms

All rows are measured-by-us. The 15.17.0 row comes from bun bench/claude-mem-baseline.mjs --data bench/data/locomo10.json --port 37795 --out bench/results/2026-11-11/claude-mem-15.17.0.json, against a claude-mem 15.17.0 worker from npm pack claude-mem@15.17.0. The 15.2.0 row comes from the same script, from an earlier run whose date and raw output are not kept. Re-run the Aletheia rows and print the claude-mem rows with bun scripts/compare-bench.mjs. It reads the JSON files in bench/results/ and needs no network. Benchmarks has every command and the full table.

On 15.17.0, Recall@5 by question category was 17.6% (category 1, 282 questions), 48.3% (category 2, 321), 22.2% (category 3, 92) and 52.7% (category 4, 841). Recall@10 was 50.0%.

Read these numbers with five caveats.

  1. The two claude-mem rows differ in version and in recorded conditions. The rise from 36.0% to 43.5% cannot be assigned to the version alone, because the 15.2.0 run's Chroma state, date and machine are unknown.
  2. claude-mem is built to ingest through its language-model observer. The baseline saves raw turns through its save endpoint, which is the closest model-free equivalent. A run through the observer could score differently.
  3. Chroma was running for 15.17.0. It indexes saved turns in the background, and the harness waits a fixed 15 seconds per conversation, so some turns may not have been in the vector index when their questions ran. This was not measured. Chroma needed about 1 GB of downloaded Python packages and an embedding model in the temporary home, and the first run needed the package cache filled before the worker could start it.
  4. The Aletheia hybrid row needs the optional embeddings package. Latency is not like for like: Aletheia's figure is the mean time of the in-process ranking call and leaves out the time to embed the question. claude-mem's figure is an HTTP request to its worker, measured on a busy shared machine while Chroma was embedding.
  5. One run per version. No repeat runs, so run-to-run variation is unknown.

Using both

Aletheia and claude-mem can run side by side. They use separate data directories, ~/.aletheia and ~/.claude-mem by default, and separate ports. Aletheia never writes to claude-mem's database. The importer opens it read-only with PRAGMA query_only ([src/hub/importers.mjs](https://github.com/mohamed-ashraf-elsaed/aletheia-mem/blob/main/src/hub/importers.mjs)).

claude-mem describes itself as injecting relevant context into future sessions (the repository description, 2026-10-29), and Aletheia's SessionStart hook for Claude Code prints a context block. If both are installed on one host, expect two context blocks. This page does not claim a tested combination. Run aletheia install claude-code without --write first to see every file it would change.

Migrating

To copy your claude-mem memories into Aletheia, run:

aletheia import claude-mem

The command reads observations, session summaries and prompts and adds them to the hub. Add --path <db> for a database in another place and --no-prompts to skip prompts. The step-by-step guide is Migrate from claude-mem.

Licence and attribution

Aletheia is Apache-2.0. A few files come from claude-mem 15.2.0, also Apache-2.0: the optional legacy viewer, two skill prompts, some scripts and one derived module. NOTICE.md lists each file and the change made.
