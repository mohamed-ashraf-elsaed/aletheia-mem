The surface ramp, border, status colours (success, warning, danger, info) and the highlight colour are our choice. The logo has no green, amber or red, so those four are picked for contrast, not sampled.

Tokens

  • Surfaces 0 to 3, border, strong border, text, muted text, accent, accent-2, node, accent-ink, accent-soft, glow.
  • Status: success, warning, danger, info.
  • Type scale: 12, 13, 15, 18, 24, 32 px as --ui-text-xs to --ui-text-2xl. System font stack only. A monospace stack for ids, paths and code. Arabic falls through to the system Arabic face.
  • Spacing: 4, 8, 12, 16, 24, 32, 48 px.
  • Radius: 6, 10, 16 px and a pill.
  • Shadow: three levels. Glow: a 1 px ring plus a soft halo in the accent colour. Focus ring: two rings.
  • Motion: 120, 200 and 320 ms. Three easings: standard, out and a small spring. Under prefers-reduced-motion the three durations collapse to 0.01 ms.
  • Touch target: 40 px.

Themes

Dark is the base because the logo is dark. Light is a full alternative. The default is prefers-color-scheme. The header toggle sets Auto, Dark or Light and stores it in localStorage under aletheia.theme. The automatic light block and the manual light block must match; a test checks that.

Contrast

Ratios are computed by bun scripts/contrast.mjs (WCAG 2 relative luminance) and checked by test/ui-contrast.test.mjs. Text pairs need 4.5:1. Control edges and the accent against surfaces need 3:1.

Brand details

  • The brain mark is an inline SVG of connected nodes. It sits in the header and animates as the loading mark: the nodes pulse one after another.
  • The favicon is an SVG that changes in three states (idle, working, error) by swapping a data URL in JavaScript.
  • The empty-state picture is an inline SVG that uses the same palette through CSS variables.
