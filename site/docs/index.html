Aletheia documentation

Aletheia (aletheia-mem) is a free, local memory and rules hub for AI coding tools. These 49 pages cover installing it, connecting Claude Code, Codex CLI, Cursor, Gemini CLI, Windsurf and OpenCode, how memory and rules work, the CLI, MCP and REST reference, and how it compares with claude-mem and other memory tools. The Markdown in docs/ is canonical.

AI tools can read llms.txt or llms-full.txt. Every page also has a plain Markdown copy at the same address ending in .md.
