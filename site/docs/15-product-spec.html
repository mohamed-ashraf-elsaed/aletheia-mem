15.1 What "1000% better" and "beat it by 100%" mean here

Neither phrase is a metric. A product cannot be "1000% better" without saying at what. This spec replaces them with a scorecard of measured ratios against claude-mem as shipped. "Beat by 100%" becomes "at least 2.0× on the primary metric, same data, same hardware", and each row says whether it has been met. Anything not measured is marked not measured and does not count.

15.2 Vision, problem, users

Vision. Your AI tools remember what matters, follow your rules, and none of it is locked in one vendor, one account, or one cloud.

Problem. Every coding agent forgets between sessions. The tools that fix it are tied to one agent, send data to a vendor by default, charge for hosting and team features, and inject large context blocks that measurably can lower agent success and raise cost.

Personas.

PersonaNeedsPain today
Multi-tool developer (Claude Code, Cursor, Codex in one week)One memory and one rule set across tools; nothing to pay forInstructions copied by hand into 4 files; memory stuck in one tool
Privacy-sensitive developer / companyNo account, no telemetry, secrets never stored, local modelsDefault-on telemetry; hosted processing
Team leadShare decisions and conventions without a cloudTeam sync is a paid tier
Tool or agent builderA stable, documented memory API and formatEach memory system has its own shape

Non-goals (v1). Hosted cloud. Billing. Accounts. A new IDE or agent. A token or any financial product. Multi-tenant SaaS. Replacing the model provider's own memory features.

15.3 Principles

  1. Inject little, retrieve on demand. Memory text in the prompt has a cost and can hurt (14). Default to a small, ranked, budgeted context and let the agent search for more.
  2. Everything is provenance-linked. Every recalled item points to the raw event that produced it.
  3. Local and private by default. Loopback only, redact before store, no telemetry, optional model calls are explicit and costed.
  4. Open formats, easy exit. The bundle format is versioned and documented; export is one command.
  5. Measure, then claim. The benchmark harness is part of the product repo and runs in CI.
  6. Small core, adapters at the edge. The store and retrieval pipeline know nothing about any tool.
