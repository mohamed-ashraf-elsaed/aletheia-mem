Keyboard and small-screen walk: Requests, Goals, Story, Suggested rules, Economics

Date: 2026-10-27. Task: T-224.

What was run

  • Server: ALETHEIA_PORT=37894 bun bin/aletheia-server.mjs --host 127.0.0.1 on a data folder made by bun scripts/seed-demo.mjs --data <scratch>/data --rows 150. The server ran with the real HOME; it only read the scratch data folder.
  • Browser: the Playwright MCP browser (Chromium), driven with page.keyboard, page.evaluate and emulateMedia. Measured by us, not by a screen reader.
  • Pages, all with ?demo=1: #/work, #/work/request/<id> (a shipped request, a request whose title holds a 200-character unbroken token, a request whose title is long Arabic), #/rules/suggestions, #/rules (Replace dialog) and #/memory/economics.
  • Viewports: 1280x900 and 375x812. Schemes: light and dark. Reduced motion: prefers-reduced-motion: reduce.
  • Seed change: scripts/seed-demo.mjs now adds two requests (long Arabic title, 200-character token title) and one suggested rule with long Arabic text plus a 200-character token. All rows are labelled demo.
  • Tab walk: 60 presses of Tab per page at 1280 px; every stop was recorded with its role, name, focus ring, on-screen state and aria-expanded.

Failures found, with selectors

  1. a.ui-estimate was 59x20 or 68x23 px (touch target). Found on every page that prints the label.
  2. .ui-meta li > a (the #42 pull request link on the request detail page) was 23x40 px.
  3. After a keyboard Dismiss on #/work or Approve or Reject on #/rules/suggestions, document.activeElement was body. The card was hidden and then the list was rebuilt, so a keyboard user restarted from the page top.
  4. Thirteen links on one page all had the name "estimated" (the explanation was only a title).
