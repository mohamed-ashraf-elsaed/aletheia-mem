## Goal

Batch 20-40 episodes per call, cap input tokens, and store model id, input/output tokens and estimated dollars per call.

## Why

D1 F-M09, F-M11; D4 section 23.7. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/facts.mjs`
- `src/hub/usage.mjs`
- `test/fact-budget.test.mjs`

## Steps

1. Chunk by episode count and character budget.
2. Truncate tool output before prompts.
3. Write a usage row per call and expose totals.

## Acceptance criteria

- [ ] A window never exceeds the configured budget.
- [ ] Usage rows match the calls made.
- [ ] A provider error does not lose the queue.

`chunkEpisodes` is bounded by `ALETHEIA_FACT_MAX_EPISODES` (default 20, clamped to 40) and
`ALETHEIA_FACT_CHAR_BUDGET` (default 12,000). Usage rows carry model, mode, input/output tokens, facts, status,
raw rejected output and an estimated cost from `ALETHEIA_PRICE_IN_PER_1K` / `ALETHEIA_PRICE_OUT_PER_1K`. Prices
default to 0, so the default dollar figure is 0 rather than a guessed vendor rate. The test's dollar figures use
1 and 2 per 1k tokens as fixture prices, not a claim about any vendor.
