## What changed

- `public/ui-guide.js`: a three-step card shown while the store has no memories and no facts. Step 1 (install capture) has a tool picker, a preview command and the write command, each with a Copy button, and turns done by itself when the doctor sees every expected hook. Step 2 says what to do. Step 3 shows the brain loader and "Waiting for the first event" and polls every 3 s; when data arrives all steps turn done, it says which tool the first memory came from, and a moment later the guide closes and the counts and list reload. "Hide this guide" is remembered in localStorage.
- `public/tabs/memory.js`: mounts the guide above the counts when the store is empty.
- `test/ui-guide.test.mjs`: 15 tests.
- Checked in Chromium on an empty store: the guide shows, a note posted through the API flipped it and the page then listed the new memory.
- The Work tab is not changed yet; the guide can be mounted there in T-215.
