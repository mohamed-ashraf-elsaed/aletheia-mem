## Goal

Find near-duplicate observations with TF-IDF cosine and an IDF veto, above an exact-hash fallback.

## Why

[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Steps

1. Build a term-frequency vector over title + narrative.
2. Weight by inverse document frequency.
3. Return candidates >= 0.85; auto-merge >= 0.92.

## Acceptance criteria

- [ ] Exact duplicates still collapse.
- [ ] The scan is bounded at 50k rows.
