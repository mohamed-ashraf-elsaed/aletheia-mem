# T-071: Add uninstall for every installer

Status: validated
Phase: P3
Depends on: T-058
Validated on: 2026-10-26
Evidence:

## Goal

Restore every file changed by an install, byte-for-byte, including removing hooks and the MCP entry.

## Why

D5 section 24.4. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/install.mjs`
- `bin/aletheia.mjs`
- `test/uninstall.test.mjs`

## Steps

1. Read the install manifest.
2. Restore backups or reverse the exact edit.
3. Remove the manifest.
4. Refuse when a file changed after install unless `--force`.

## Acceptance criteria

- [x] A dry-run install then uninstall leaves the tree identical.
- [x] A changed file is refused.
- [x] A partial install can be undone.
- [x] `install --list` names each tool's capability and verification.
