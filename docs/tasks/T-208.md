## Goal

Memories, facts, search results and dismissed items with filters, pagination, highlighting and optimistic actions with undo.

## Files to touch

- `public/tabs/memory.js`

## What changed

- `public/tabs/memory.js`: one frame per project (title, five counts that link to their pages, page links with Review and Hidden counts, New note, Import and export), then the page inside it. The import panel keeps the form for the older memory database (read-only) and shows a progress bar for imports and compress.
- `public/tabs/memory-views.js`: memories (text, type, dates, kind, scope, pinned, sort), facts (text, Current, History, Dismissed, scope, dates, sort), dismissed (by type, with what was hidden) and search (facts then memories, scope, history, dates, kind, counts, channel chips). Each is a server-paged list with page and filters in the URL hash.
- `public/ui-views.js`: filter controls that follow Back and Forward, memory, fact and dismissed cards. Pin, Dismiss, Restore are optimistic with an 8 s Undo and roll back on failure; Edit and New note are dialogs. Narrative text is Markdown through the safe renderer, search words are highlighted.
- `public/ui-components.js`: `highlightNodes` and a Markdown view that highlights, a lazy `disclosure`, an `enterList` that skips the animation on a background reload.
- `src/hub/routes.mjs`: `/api/hub/review` accepts `items=0` and `dupes=0`, so each list asks only for what it shows.
- `test/ui-memory.test.mjs`: 35 tests (fake DOM, fake fetch, fake location). `test/support/fake-dom.mjs` restores globals; `later()` in ui-dom keeps late timers from touching a gone document.
- Checked in Chromium on the seeded server: paging, `]`, Back, filter in URL, reload, highlight, optimistic dismiss with Undo, pin, every sub page, no console errors.

- [x] Pin, dismiss and restore are optimistic with an 8 s undo.
