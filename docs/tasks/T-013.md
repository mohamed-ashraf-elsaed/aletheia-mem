## Goal

Fail when a relative link or anchor in README/docs points to a missing file or heading.

## Why

D5 section 24.4. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `scripts/check-docs-links.mjs`
- `package.json`

## Steps

1. Walk README.md and docs/**/*.md, skipping fenced code blocks.
2. Resolve relative links and check file existence.
3. Check `#anchor` against a GitHub-style slug of headings.
4. Ignore external URLs but count them.

## Acceptance criteria

- [ ] A broken relative link fails with the file and line.
- [ ] External links are counted, not fetched.
- [ ] Exit 0 on the current tree.

## Validation command

```bash
bun scripts/check-docs-links.mjs
```

Expected: links ok: <n> local, <n> external
