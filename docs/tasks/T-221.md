## Goal

Show `GET /v1/work/story` as a panel in the Work tab and `GET /v1/context/economics` as a page in the Memory tab.

## What changed

- The Work tab gains a Build story section: counts (shipped, working, waiting on you, idle), the shipping velocity
  (`perWeek`, `averageDaysToShip` or "n/a"), and the learned habits with their `timesSeen` and dated quotes. An empty
  store says so.
- Memory gains an Economics page: the totals strip (observations, read tokens, work tokens, savings), the documented
  read-token counter, and one row per context memory with `readTokens`. When `workTokens` is null the row prints
  "n/a" and `workTokensSource`; it never prints zero or a made-up number. Savings prints "n/a" when null.
- The read-token counter is labelled "estimated" with the UNVERIFIED link, since four characters per token is an
  estimate.
- The panel homes are the Work tab (story) and the Memory tab (economics), as the task asks, so no alternate home is
  recorded.

## Acceptance criteria

- [ ] The story panel shows counts, velocity and learned habits with dated quotes.
- [ ] The economics page shows totals and per-observation read tokens.
- [ ] A null `workTokens` shows "n/a" and the written reason; no number is invented.
- [ ] The new Memory page passes the accessibility audit.
