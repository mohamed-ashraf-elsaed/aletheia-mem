Install each rules target in a real tool or a pinned container and record what the tool actually reads.

## Why

## Steps

1. For Claude, Codex, Gemini, Cursor, Windsurf, Copilot and Aider, test in a temp project.
2. Open the tool or its documented parser and confirm the rule is read.
3. Record tool version and date.
4. Remove or mark any format that does not work.
