## Goal

Install each rules target in a real tool or a pinned container and record what the tool actually reads.

## Why

D1 F-L04, F-I09. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `test/install-targets/rules.test.mjs`
- `docs/verification/rules-targets.md`
- `src/hub/tools.mjs`
- `src/hub/rules-sync.mjs`

## Steps

1. For each target, read the tool's current documentation and record path + format + date.
2. Confirm the documented parser/format rather than guessing.
3. Record the date and source.
4. Fix or mark any format that does not match.

## Acceptance criteria

- [x] Every target has a dated row with a source.
- [x] A failure removes the claim from the README (README claims are updated in T-141).
- [x] The registry stores `verifiedOn` and `source` for every target.
