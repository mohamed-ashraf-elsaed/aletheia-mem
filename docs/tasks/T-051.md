Measure answer accuracy with a fixed reader and judge across no-memory, full-context, retrieval and packed arms.

## Files to touch

## Steps

1. Load the 500 questions and histories.
2. Run each arm with the same reader prompt.
3. Score with one judge prompt.
4. Write per-question NDJSON with answers, tokens and latency.

## Acceptance criteria

- [ ] All four arms run from one command.
- [ ] Every question has a raw answer and a verdict.
- [ ] A rerun reproduces the score within 2 points.
