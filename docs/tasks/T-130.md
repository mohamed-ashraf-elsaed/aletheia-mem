## Goal

A fact seen in two sessions is one current fact with two episode sources. Near-duplicate observations created by the
worker are merged through the existing audited merge, never deleted silently.

## Why

[26-memory-pipeline.md](../26-memory-pipeline.md) section 26.7 lists "automatic dedupe and merge" as not built;
[23-memory-building.md](../23-memory-building.md) section 23.5.6 defines the policy.

## Steps

1. When `addFact` returns an existing row, link the new episodes to it instead of discarding them.
2. After a job writes observations, run the near-duplicate scan and merge auto pairs through `mergeObservations`.
3. Return how many facts were deduplicated and how many observations were merged.

## Acceptance criteria

- [ ] Two episodes with the same fact give one active fact and two episode sources.
- [ ] A near-duplicate observation created by the worker keeps one row with a `duplicate_of` link and an audit row.
- [ ] Nothing is deleted.
