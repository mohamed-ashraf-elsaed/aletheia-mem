## Goal

Attach "what came out of it" to a request: commit shas, PR URLs/numbers and branch references found in stored tool
events. Each finding keeps the tool-event id it came from.

## Files to touch

- `src/hub/artifacts.mjs` (new)
- `src/hub/requests.mjs`
- `test/artifacts.test.mjs` (new)

## What changed

- `detectArtifacts(text)` is a conservative, pure detector: a commit needs a `commit <sha>` lead-in, a full 40-hex
  sha, or a bracketed `[branch sha]` shape; a PR needs a GitHub pull URL or `pull request #N`; a branch needs a
  `git push ... origin` lead-in or a feat/fix/chore-style name.
- `cameOutOfIt(store, {project, sessionIds})` scans the named sessions' tool events (memory `event` rows and episode
  tool rows) and returns the findings with `at`, `evidenceId`, `source` and `sessionId`.
- `buildRequest` attaches `cameOutOfIt` (the full list) and `outcome` (commit, pull and branch counts) to each request.

## Acceptance criteria

- [x] A PR URL, a bracketed commit+branch, a push branch and a PR number are all detected.
- [x] A request carries its commit, PR and branch evidence ids.
- [x] `cameOutOfIt` scans only the named sessions; no sessions gives an empty list.
