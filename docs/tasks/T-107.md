## Goal

Streamable HTTP MCP with Origin checks, a read-scoped bearer token, audit, and instructions for a tunnel.

## Why

The owner decided on 2026-10-26 that every paid feature of claude-mem and its rivals is built here for free and self-hosted. D7 `docs/27-free-paid-parity.md` feature F8; research in [27-free-paid-parity.md](../27-free-paid-parity.md).

## Files to touch

- `src/hub/sync/server.mjs`: serves `/mcp` on the sync hub when `hubDb` is given; bearer-token auth with
  `mcp`/`read`/`sync`/`admin` scopes, project scope, per-token rate limit, audit rows, origin allow-list, the
  `requiresTlsProxy` helper.
- `src/hub/mcp-http.mjs`: added the `rateLimit` hook (shared with T-067).
- `src/hub/sync/cli.mjs`: `aletheia mcp-link create|list|revoke` (hub-side, prints the URL with no secret in the
  path plus the Claude Code and Claude Desktop client config).
- `bin/aletheia.mjs`, `bin/aletheia-sync.mjs`: wire the command; `--hub-db` and `--mcp-origins` flags.
- `src/hub/routes.mjs`, `public/tabs/tools.js`: the "Remote access" section of the Tools tab (create/list/revoke).
- `docs/30-remote-mcp.md` (new), `docs/27-free-paid-parity.md`, `docs/manual-test.md` (§9, NOT RUN BY AUTHOR).
- `test/remote-mcp.test.mjs` (new): the validation test.

## Acceptance criteria

- [x] The behaviour in Goal is observable in the test (scoped read-only tokens, project scope, revoke, audit,
  rate limit, Origin allow-list, TLS-proxy rule).
- [x] Nothing leaves the machine unless the user configured a remote (the endpoint is on the sync hub, which
  binds loopback by default; a non-loopback bind warns unless `--behind-tls`).
- [x] Failure modes listed in docs/27 for this feature are each tested or marked not built (token revoked
  mid-call → 401; read token cannot write; audit row per call with no payload; per-token rate limit → 429;
  E2EE-account unlock mode is not built — it belongs to T-117 and is marked in docs/30 §30.4).
