## Goal

A decide flow for rules: approve / edit-then-approve / reject a suggestion, decided counts, an on/off toggle for
active rules, a "last learning run" record, and a "replaced by <rule> on <date>" history (the T-072 extension).

## Files to touch

- `src/hub/rules-decide.mjs` (new)
- `src/hub/store.mjs`: `replaced_by` / `replaced_at_epoch` columns on `rules` (additive) and the shape exposes them.
- `src/hub/routes.mjs`
- `test/rules-decide.test.mjs` (new)

## What changed

- `decideSuggestion` approves a suggestion as-is, edits its text first (`edit`), or rejects it. Approval creates a
  rule and marks the suggestion accepted; rejection dismisses it; both resolve the pending review row.
- `decidedCounts` returns total / decided / pending; `GET /api/hub/rule-suggestions` includes those counts.
- `toggleRule` turns a rule on or off via `rules.update({enabled})`, never deletes it.
- `replaceRule` creates the replacement rule and records `replaced_by` / `replaced_at_epoch` on the old one.
- `recordLearningRun` / `learningRun` store and read the last learning run (time, found, proposed, errors).
- Routes: `POST /api/hub/rule-suggestions/:id` gains `approve` / `edit` / `reject`; `POST /api/hub/rules/:id/toggle`,
  `POST /api/hub/rules/:id/replace`, and `GET`/`POST /api/hub/rules/learning-run`.

## Acceptance criteria

- [x] Approve creates a rule; edit-then-approve uses the edited text; reject dismisses.
- [x] Decided counts are returned.
- [x] Toggle turns a rule off and back on without deleting it.
- [x] Replace records "replaced by <rule> on <date>".
- [x] The learning run record survives and the decide routes answer.
