## Goal

Publish `aletheia-mem` with the three bin entries so `npx aletheia-mem` works on a fresh machine.

## Why

D5 section 24.3.2, 24.5. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `package.json`
- `scripts/release.mjs`
- `.github/workflows/npm-publish.yml`

## Steps

1. Add `files` and `publishConfig` to package.json. Keep `bin` and `engines`.
2. Verify the tarball contents with `bun pm pack --dry-run` (via `scripts/release.mjs`).
3. Do NOT publish. Record the exact owner steps below.

## Acceptance criteria

- [x] The tarball contains bin, src, docs and NOTICE.
- [x] `npm view aletheia-mem version` returns the version. Run 2026-10-27: `dist-tags.latest` = `0.1.0`, versions `0.0.0-stage` and `0.1.0`.
- [x] The `npx aletheia-mem --version` smoke test passes. Run 2026-10-27 in a clean temp directory: prints `0.1.0`. The owner's first try a few minutes after publishing failed with "could not determine executable to run"; the registry still showed only the `0.0.0-stage` placeholder. It worked once `0.1.0` propagated (about 5 minutes).

## Validation command

```bash
bun scripts/release.mjs
```

Expected: pack ok: 4 required paths present

## Evidence

```text
pack ok: 4 required paths present
```

`bun pm pack --dry-run` shows 437 files (bin, src, docs, prompts, vendor, public, public-hub, NOTICE, LICENSE,
README, CHANGELOG). The package is **prepared, not published**. `npm view aletheia-mem version` is UNVERIFIED
until the owner publishes it, and no `npm-publish.yml` workflow was created (publishing stays a manual owner step;
`test/release-files.test.mjs` asserts that workflow does not exist).

Owner-only steps, in order:

1. `npm login` (this completes the npm 2FA challenge).
2. From the worktree, after the final green validation: `npm publish --access public` (the default tag is `latest`).
3. Tag explicitly if needed: `npm dist-tag add aletheia-mem@0.1.0 latest`.
4. Verify on a fresh machine: `npm view aletheia-mem version` and `npx aletheia-mem --version` in a clean directory.
