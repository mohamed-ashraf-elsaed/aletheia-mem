## Goal

One read-only query layer that turns the hub tables into the Work view: active sessions, recent facts, review
items, queue depth, pinned items, recent dismissals and the last capture per tool.

## Files to touch

- `src/hub/work.mjs`
- `src/hub/routes.mjs`
- `test/work.test.mjs`

## What changed

- `workOverview(store, {project, now, ...})` merges the memory and episode views of a session, so a hook capture is
  visible before the worker writes episodes and a back-filled transcript is visible without memories. It returns
  counts, the last typed prompt, the last summary with its source facts, recent current facts, pinned memories,
  pending review items, pending rule suggestions, queue state, dismissals in the last N hours, and the last capture
  per tool.
- `sessionDetail(store, {sessionId, project})` returns the ordered timeline, summary and facts with their source
  episodes.
- `GET /v1/work`, `GET /v1/work/session/:id` and `GET /v1/work/goals` (the last is implemented in T-144).
- Every value is read from a row. An empty store returns arrays and `empty: true`, not placeholder counts.

## Acceptance criteria

- [x] A project filter and all-projects mode return different sessions.
- [x] Each session has last-event time, prompt count, tool-event count, last user prompt and the last summary with
      its source facts.
- [x] Recent current facts, review items, rule suggestions, queue depth, pinned items, dismissals and last capture
      per tool are present.
- [x] A session id returns the timeline, summary and facts with sources; an unknown id is 404.
- [x] An empty database returns empty arrays and `empty: true`.
