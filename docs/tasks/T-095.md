## Goal

Sync two stores without a server conflict: every mutation is an op with an HLC, and merge is deterministic.

## Files to touch

- `src/hub/oplog.mjs`
- `test/oplog.test.mjs`

## Steps

1. Record add, update, delete and merge ops.
2. Order by HLC with a tie-break on device id.
3. Apply idempotently.
4. Add tombstones for deletes.

## Acceptance criteria

- [ ] Two stores converge after exchanging ops in any order.
- [ ] A replay adds nothing.
- [ ] A delete wins over an older update.
