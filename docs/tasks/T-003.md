## Goal

Fail loudly with a useful message when a claude-mem database is missing tables or columns, instead of importing zero rows silently.

## Why

D1 F-C10; docs/15 NFR-10. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/importers.mjs`
- `test/importer-schema.test.mjs`

## Steps

1. Before reading rows, query `sqlite_master` for the required tables.
2. Query `PRAGMA table_info` for the required columns.
3. Throw a RangeError naming the missing table/column and the database path.
4. Add a test with a stripped database.

## Acceptance criteria

- [ ] A database without `observations` throws with the table name.
- [ ] A database with a missing column throws with the column name.
- [ ] A valid fixture still imports.
