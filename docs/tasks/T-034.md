## Goal

Support none, local OpenAI-compatible, OpenAI, OpenRouter-style and Claude CLI providers, with a mode that changes extraction behaviour and output language.

## Why

## Files to touch

- `src/hub/modes/*.json`

## Steps

1. Define a provider interface with `ask(prompt, opts)`.
2. Add `mode` (code, chill, language) and pass it to the prompt.
3. Fail with a clear message when a provider is misconfigured.
4. Do not make a network call when provider is `none`.

## Acceptance criteria

- [ ] `none` makes zero network calls.
- [ ] A local endpoint completes a fixture extraction.
- [ ] A mode changes the output language in a fixture.
