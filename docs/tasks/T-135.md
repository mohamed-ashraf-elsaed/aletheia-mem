Status: validated
Phase: P6
Depends on: T-134
Validated on: 2026-10-26

## Goal

The Memory tab carries the existing Hub memory features and adds a facts list with a current/history toggle.
Each fact shows its source, `valid_at`, importance, scope and extractor mode. Search shows which channels ran,
from the T-004 response.

## Why

The facts are the durable layer of the pipeline (T-017 to T-032) and there was no page that showed them. Part A
of the `feat/one-ui` work order.

## Files to touch

- `public/tabs/memory.js` (new): memories list with pin/edit/dismiss, new note, facts current/history, search with
  channel chips, dismissed rows with restore, import/export.
- The facts route (`GET /api/hub/facts`) and the dismiss/restore routes were already committed with T-134.

## Acceptance criteria

- [x] Memories can be listed by project, searched, pinned, edited, created and dismissed (reversible).
- [x] Facts show source episode, `valid_at`, importance (with its source), scope and extractor mode.
- [x] Current is the default; History shows superseded and cold rows.
- [x] A header search calls `/v1/search` and prints the channels and the empty-result reason.
- [x] Dismissed rows are listed with Restore.
