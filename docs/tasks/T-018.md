## Goal

Turn a round of activity into 0-5 atomic facts with resolved subjects, absolute dates and episode provenance.

## Why

D3 E02; D4 section 23.5.2; D1 F-M01. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/facts.mjs`
- `src/hub/prompts/facts.txt`
- `test/facts.test.mjs`

## Steps

1. Write the fact prompt from D4.
2. Validate every field, cap the array at 5, require at least one existing episode id.
3. Retry once with the validation error.
4. Store facts with `observation_id`/`episode_id`.

## Acceptance criteria

- [ ] Malformed output is rejected with a useful message.
- [ ] An orphan fact is rejected.
- [ ] A fixture round produces the expected facts.

## Validation command

```bash
bun test test/facts.test.mjs
```
