## Deviations

- 2026-10-26: summaries have no model prompt in this build. `summaries.mjs` builds them from fact text, so the
  summary language follows the facts automatically. There is no separate summary-language variable to set.
- 2026-10-26: the setting is a JSON map in `settings` (`output.language`), not a column, so an old database needs
  no migration. `ALETHEIA_OUTPUT_LANGUAGE` applies when a project has no entry.
