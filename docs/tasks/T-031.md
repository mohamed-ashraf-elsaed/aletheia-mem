## Goal

Decay rank over time and shorten old episode text after a retention period, with an audit row for every change.

## Why

D4 section 23.5.8; D1 FR-M6. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/retention.mjs`
- `test/decay.test.mjs`

## Steps

1. Define per-kind retention windows in settings.
2. Shorten episode text but keep a pointer.
3. Never prune pinned items or facts with active links.
4. Audit every change.

## Acceptance criteria

- [ ] A pinned item is never pruned in a property test.
- [ ] Every removed text has an audit row.
- [ ] Retrieval recall loss is <= 1 point on the fixture.
