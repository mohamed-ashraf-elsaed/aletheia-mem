# T-025: Invalidate contradicted facts instead of deleting them

Status: validated
Phase: P1
Depends on: T-018, T-024
Validated on: 2026-10-26
Evidence:

## Goal

When a newer fact conflicts, close the old fact's valid range, keep it queryable, and link the new fact to it.

## Why

D4 section 23.5.5; D1 FR-M3. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/facts.mjs`
- `test/contradictions.test.mjs`

## Steps

1. Group by `(project, subject, predicate)`.
2. Classify update / same-time contradiction / different sense.
3. Set `valid_to`, `status`, `supersedes_id`; enqueue same-time conflicts for review.

## Acceptance criteria

- [ ] A 30-pair update fixture resolves newest-wins >= 90%.
- [ ] No row is deleted.
- [ ] History returns both facts with ranges.

bun test test/contradictions.test.mjs
