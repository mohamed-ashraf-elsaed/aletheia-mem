## Goal

Detect explicit user corrections in episodes and propose a rule, without adding it automatically.

## Why

D1 F-L07. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/rule-suggest.mjs`
- `test/rule-suggest.test.mjs`

## Steps

1. Match correction phrases ('no, use', 'don't', 'always', 'never').
2. Extract the rule text and the project scope.
3. Insert into the review queue, never into `rules` directly.

## Acceptance criteria

- [ ] A fixture with 20 corrections proposes >= 10 rules with <= 1 false positive.
- [ ] Nothing is auto-enabled.
- [ ] Every suggestion is auditable.
