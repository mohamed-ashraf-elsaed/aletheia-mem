## Goal

Ingest session files for tools without hooks, incrementally and without duplicates.

## Steps

1. Track file offsets per session.
2. Parse known Codex rollout shapes; store unknown lines as raw messages.
3. Deduplicate by content hash.
4. Resume after restart.

## Acceptance criteria

- [x] A growing file is ingested once.
- [x] A restart does not duplicate rows.
- [x] An unknown format is stored, not dropped.
- [x] Sources are read-only, a partial line waits, and a shrunk file is re-read.
- [x] The interval is at least 1000 ms, a pass has a batch size, and the CLI sets nice 10.
- [x] The Codex rollout layout is verified from two real files on this machine, so it is included.

Implementation notes (2026-10-26):

- The Codex layout was verified from two real rollout files under `~/.codex/sessions/...` (research-log
  section D). It is included; the other hosts remain unsupported.
- The watcher imports episodes. It does not enqueue extraction jobs itself; `aletheia compress` still turns
  episodes into facts. This keeps the watcher cheap and avoids a second queue implementation.
- `nice 10` uses `os.setPriority(0, 10)` and is best effort; the interval clamp and batch size are enforced in
  the watcher itself.
- The state database is separate (`~/.aletheia/watcher.db`), so no hub migration was needed. Sources are never
  written.
