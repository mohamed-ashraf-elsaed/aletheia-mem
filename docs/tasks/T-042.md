## Steps

1. Estimate tokens with a pinned tokenizer or a documented approximation.
2. Dedupe by source episode.
3. Fill in rank order, stop at the budget.
4. Add a footer with id, date and project.

## Acceptance criteria

- [ ] The packed output never exceeds the budget.
- [ ] No source appears twice.
- [ ] Recall at a 2,000-token budget >= current top-5 recall, or the result is negative.
