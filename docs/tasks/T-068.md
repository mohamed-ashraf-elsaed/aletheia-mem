## What shipped

MCP plus global rules. No capture plugin: the official plugin page lists event names but not the fields inside
each event payload. Writing a plugin that reads `event.properties.sessionID` or similar would be a guess, which
this run's honesty rule forbids. The installer says `mcp+rules` and explains why.

## Acceptance criteria

- [x] The config shape matches the documented `mcp` key.
- [x] A second install is a no-op.
- [x] Dry run writes nothing.
- [x] The capability level is `mcp+rules`, not `full`.
