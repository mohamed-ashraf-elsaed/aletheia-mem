## Goal

Import past sessions from the tools' local transcript files through the redactor and the extraction queue, resumable and idempotent. 11 external PRs asked for back-fill.

## Why

User need found by reading claude-mem pull requests on 2026-10-26; see [A4-claude-mem-prs.md](../research/A4-claude-mem-prs.md) and [27-free-paid-parity.md](../27-free-paid-parity.md).

- `src/hub/transcripts.mjs` (new): layout lookup, parser, redaction, hash dedupe, job queue.
- `src/hub/store.mjs`: `addEpisode` now reports `created` so an import can count new turns.

- `test/transcript-backfill.test.mjs` (new).

## Verified layouts (this machine, 2026-10-26)

| Tool | Path | Lines read |
|---|---|---|
| Claude Code | `~/.claude/projects/<slug>/<session>.jsonl` | `type: user\|assistant`, `message.role`, `message.content` as a string or text parts; `cwd`, `sessionId`, `timestamp` |
| Command Code | `~/.commandcode/projects/<slug>/<session>.jsonl` | `type: session` (id, cwd) then `type: message` with `message.role` and text parts |

Skipped on purpose: `subagents/agent-*.jsonl` (Claude sidechains), `*.checkpoints.jsonl`, `*.meta.json`, and every
non-text content part. Tool payloads are not memory; the hooks already capture them live.

## Deviations and limits

- 2026-10-26: only the two formats above are supported, because they are the two that were read on this machine.
  No other tool's layout is guessed.
- 2026-10-26: `~/.commandcode/history.jsonl` is a global prompt list with no `cwd` and no session id, so it is not
  imported. Only the per-project session files are.
- 2026-10-26: extraction is queued, not run. Start the worker (`aletheia compress --daemon` or the server with
  `ALETHEIA_EXTRACTION_WORKER=1`) to turn the imported episodes into facts.
- 2026-10-26: dedupe is by a content hash of the redacted text, so the same prompt in two sessions is stored once.
  `source_ref = transcript:<tool>:<session>:<turn>` makes a re-run skip what is already there.
