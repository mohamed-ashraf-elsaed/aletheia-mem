## Goal

`GET /v1/work/story` returns the build story: shipped / working / waiting-on-you counts, a shipping-velocity line from
stored shipped dates, and "what it learned about how you work" from repeated corrections in the owner's own prompts.
Rule-based only.

## Files to touch

- `src/hub/story.mjs` (new)
- `src/hub/routes.mjs`
- `test/story.test.mjs` (new)

## What changed

- `buildStory(store, {...})` counts shipped / working / waiting-on-you / idle requests, buckets shipped requests by
  ISO week, computes the average ask-to-ship duration, and attaches `learned` preferences.
- `learnedPreferences(store, {project})` scans prompt rows (memories and user episodes, deduped by session and text)
  for corrections, groups them by rule text, and returns each with `timesSeen`, `latestAt` and dated quotes.
- `GET /v1/work/story` wires the module.

## Acceptance criteria

- [x] Counts and velocity come from shipped and working requests.
- [x] Repeated corrections become learned preferences with dated quotes.
- [x] An empty store says empty with no invented numbers.
