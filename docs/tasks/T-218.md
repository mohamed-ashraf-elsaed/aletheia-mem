## Goal

Replace the flat session list in the Work tab with the request cards from T-152, T-166, T-167 and T-173. A request
shows its status, progress with the ids behind it, an ETA when one can be measured, and what came out of it. The
existing session page (T-145) stays reachable from a request.

## Files to touch

- `public/tabs/work.js`
- `public/tabs/work-requests.js` (new)
- `public/ui-estimates.js` (new): the "estimated" label and its UNVERIFIED link.
- `test/ui-work-requests.test.mjs` (new)
- `test/ui-work.test.mjs` (update: the overview now shows requests, not a session list)

## What changed

- `GET /v1/work/requests` drives a new request list with filter (all, needs you, shipped), sort (newest, needs you,
  most progress) and group (none, by tool) controls, plus a page-size choice. The route takes `limit` but no
  `offset`, so the list uses `limit` and the server's `counts`, never a pager that would repeat the same rows.
- Each card shows status, project, tool, started time, running time, session/prompt/tool counts, progress with its
  evidence ids (`progressEvidence`), the ETA with `etaEvidence`, and `cameOutOfIt` (commit, pull and branch links).
- Dismiss posts `/api/hub/requests/:id` with `action: "dismiss"` through the optimistic helper and offers Undo
  (restore). Dismissed requests are listed in a disclosure with Restore.
- `#/work/request/<id>` loads `GET /v1/work/requests/:id` and shows "Where this came from": sessions with dated
  prompts and facts, plus links to `#/work/session/<sessionId>?project=<project>`.
- Every heuristic value carries an "estimated" link to the UNVERIFIED note: grouping, status, progress and ETA.
- The old session page and its route are unchanged.

## Acceptance criteria

- [x] The Work overview lists requests with filter, sort and group controls.
- [x] A card shows status, progress with evidence ids, ETA or an honest "no ETA yet", and what came out of it.
- [x] Dismiss is optimistic and reversible; the dismissed list restores.
- [x] A request opens its detail with where it came from, and each session links to the session page.
- [x] Heuristic values are labelled estimated and link to the UNVERIFIED note.
- [x] `test/ui-work.test.mjs` and the new test pass.
