# T-102: Build Aletheia Sync: a replicated log with per-operation results

Status: validated

## Goal

Replicate observations, facts, rules and settings between devices through a self-hosted hub (SQLite, Bun) or a shared folder, with per-operation accept/reject so one bad operation never rejects a batch.

## Why

The owner decided on 2026-10-26 that every paid feature of claude-mem and its rivals is built here for free and self-hosted. D7 `docs/27-free-paid-parity.md` feature F4; research in [27-free-paid-parity.md](../27-free-paid-parity.md).

## Files to touch

- `src/hub/sync/engine.mjs` (new): op model, deterministic hashing, conflict rules, replica merge.
- `src/hub/sync/store.mjs` (new): the hub's `sync.db` (ops, heads, devices, tokens, pairing, audit, quotas).
- `src/hub/sync/client.mjs` (new): a device's replica, outbox, cursor, push/pull, folder export/import.
- `src/hub/sync/server.mjs` (new): the `/v1/sync/*` HTTP server with bearer-token auth.
- `src/hub/sync/cli.mjs` (new): `aletheia sync ...` and `aletheia audit` commands.
- `bin/aletheia-sync.mjs` (new): the standalone sync hub binary.
- `bin/aletheia.mjs`: wire `sync` and `audit` commands.
- `src/config.mjs`: add `syncDb`, `syncHost`, `syncPort`, `syncClientDb`.
- `test/sync-core.test.mjs` (new): the validation test.
