## Goal

Projects shared between users with roles, a team search, a board and a brief, with review before sharing.

## Why

The owner decided on 2026-10-26 that every paid feature of claude-mem and its rivals is built here for free and self-hosted. D7 `docs/27-free-paid-parity.md` feature F12; research in [27-free-paid-parity.md](../27-free-paid-parity.md).

## Files to touch

- `src/hub/team.mjs` (new): team, project, member, share and entry store; `authorize()` is the single ACL gate.
- `src/hub/team-api.mjs` (new): one handler for `/v1/team/*` and `/api/hub/team/*`.
- `src/hub/sync/server.mjs`: the `/v1/team/*` routes and the `team.db` default next to `sync.db`.
- `src/hub/routes.mjs`, `src/config.mjs`: the guarded local `/api/hub/team/*` routes and `teamDb`.
- `bin/aletheia.mjs`: `aletheia team ...`.
- `public/tabs/team.js` (new only; the UI shell is wired by the UI agent later).
- `test/team-mode.test.mjs` (new): the validation test.
- `docs/31-team.md`, `docs/03-http-api.md`, `docs/27-free-paid-parity.md`, `docs/29-sync.md`.

## Steps

1. Read the feature section and the shared design in docs/27 and `docs/research/`.
2. Write the failing test named below first.
3. Implement the smallest version that passes; record any deviation from the design here with a date.
4. Run the validation command and paste the real output.

Deviation, 2026-10-26: shared memory is a copy into `team_entry`, not a live join over the hub store. The local
`/api/hub/team/*` route acts as the local operator (the route is already guarded), because the single-user Hub
has no member token of its own; bearer-token calls always run the member ACL. Team brief and search need readable
text, so team mode is documented as plaintext-only (E2EE is not covered).
