## Goal

Install every full-capability host into a temp HOME, feed the recorded payload shape through the real installed
hook command, and show that rows exist, no secret is stored, and hook work stays under 100 ms.

## Why

The per-tool tests call the adapter directly or one command at a time. This one runs the same path a user gets:
the command written into the tool's config, a temp HOME, a temp data dir and a temp project.

## Files to touch

- `test/e2e-more-hosts.test.mjs`

## Covered hosts

`claude-code`, `command-code`, `cursor`, `codex`, `gemini-cli`, `windsurf`.

OpenCode is not here: it ships `mcp+rules` and has no hook command (T-068).

## Acceptance criteria

- [x] Every host is installed with `install <tool> --write` in a temp HOME.
- [x] The command is read back from the tool's own config file.
- [x] A recorded payload set is piped through it; prompt/tool/summary rows match per host.
- [x] No `sk-ant-` key or bearer token is stored.
- [x] Hook work p95 is under 100 ms for every host.

## Note on the measurement

The p95 measures `runHook` work (open, redact, write, close), as the existing e2e test does. The host's process
spawn is outside it; the subprocess runs in the first test only check exit 0 and rows.
