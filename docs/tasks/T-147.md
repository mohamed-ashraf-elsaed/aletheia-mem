## What changed

- `test/work.test.mjs` covers the query layer and `/v1/work`, `/v1/work/session/:id` on a seeded DB and an empty DB.
- `test/work-views.test.mjs` covers the header, session card, needs items, fact line, goal, session detail and the
  empty-state instruction without a DOM.
- `test/work-ui-contract.test.mjs` fetches the served `/`, checks every Work module and tab module for
  `claude-mem`, `103.3K` and `github.com/thedotmack`, checks the classic page still serves its bundle, and checks
  the docs no longer describe the old app as the default.
- Two tabs are allowed to name the old product, and neither is the default Work tab: Tools has the required
  "Classic claude-mem viewer (reads ~/.claude-mem, read-only)" link, and Memory keeps its existing import form and
  API route. The contract test asserts those are the only mentions and that no star count or repository URL is
  present. This is the one place the literal "all `public/tabs/*.js`" requirement conflicts with rule 4.
- README, `docs/26` §26.9 and `docs/manual-test.md` §6 now describe the new Work view and the optional legacy page.
- A real Chromium pass through the connected Playwright MCP browser used a seeded temporary hub and opened
  `#/work` and `#/work/session/s1?project=shop`: sessions, review items, facts, goals and the session timeline all
  rendered; zero console errors. Pixel width, keyboard-only and the 10 s timer under a real host remain NOT RUN.
