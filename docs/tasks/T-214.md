## What changed

Findings from a real Chromium pass on the seeded server (60 route and width combinations: 15 routes at 375, 768, 1280 and 1920 px, in the Playwright browser, with a 200-character unbroken token and an Arabic paragraph in the data), and what was fixed:

- Horizontal scroll at 375 px on every page (document width 1007 px): the visually hidden status text sat outside any positioned parent, so it escaped the status strip's scroll container. `.ui-statusbar` is now positioned and `.ui-sr` is pinned to the top-left corner. Fixed.
- Horizontal scroll on the Tools page (1842 px at 375 px, 2020 px at 1280 px): grid children with long commands and paths set the column width. `.ui-item`, `.ui-commands` and `.ui-command-row` now use `minmax(0, 1fr)`. Fixed; no page overflows at any of the four widths.
- Touch targets under 40 px: buttons (36 px), chips (36 px), the theme switch (34 px), status items (36 px), the brand link (27 px), copy buttons (26 to 32 px), a session title link (23 px) and links inside meta lines (20 px). All now use `--ui-touch` (40 px). The only targets left under 40 px are disabled Markdown task-list checkboxes and checkboxes whose whole label is 40 px tall.
- Heading order: pages went from h1 straight to h3 (row titles). Each page now carries a hidden h2 with its name.
- A keyboard walk (45 Tab presses on Memory, Write to tools and Tools): the order is skip link, brand, tabs, project, search, theme, status items, then the page; every stop is on screen and shows a 2 px ring or a double ring. The two date inputs first looked ringless only because the ring animates in over 120 ms.
- No control without a name, no duplicate ids and no unknown ARIA roles on any page.
- Reduced motion and the animation audit are in T-213.

`test/ui-a11y.test.mjs` (30 tests) renders Memory (5 pages), Rules (4), Tools (5), Work (overview and session), the first-run guide, the shortcut sheet, the palette and the dialogs with realistic API answers, and checks every control for a name, every role, ids, tab order, dialog names, live regions, and a `dir` on every element that shows right-to-left text. It also reads the stylesheets: focus rings, 40 px targets, wrapping rules, the hidden-text helper, and the small-screen rules. The audit has its own tests so it cannot pass by looking at nothing.
