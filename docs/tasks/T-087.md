# T-087: Add the i18n workflow and drift checker

Status: validated
Phase: P4
Depends on: none
Validated on: 2026-10-26
Evidence:

## Goal

Keep translations honest: each file records the English hash and CI fails when the source changes without an update.

## Why

D5 section 24.2. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `scripts/i18n-check.mjs`
- `docs/i18n/.translation-state.json`
- `docs/i18n/TEMPLATE.md`
- `test/i18n-check.test.mjs`
- `package.json`
- `.github/workflows/ci.yml`

## Steps

1. Hash the translatable text of README.md, excluding code fences and the switcher.
2. Store the hash per language with a date.
3. Fail when a language is stale, unless `--warn` is passed.
4. Add `check:i18n` to package.json.

## Acceptance criteria

- [x] A changed README makes every translation stale.
- [x] `--update` records a new hash.
- [x] The checker exits 0 on a fresh set.

## Validation command

```bash
bun scripts/i18n-check.mjs
```

Expected: i18n ok: <n> languages current
