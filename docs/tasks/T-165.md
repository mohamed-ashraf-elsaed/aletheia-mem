# T-165: Add a temp-dir test helper and fix the migration test leak

Status: validated
Phase: P0
Depends on: none
Validated on: 2026-10-26
Evidence: see the Validation section below.

## Goal

A shared helper registers every temp directory a test creates under the OS temp root and removes it in
`afterAll`, so a test that runs repeatedly never fills the disk. Fix the known leak first: `test/migration-v3.test.mjs`
left a 41 MB `/tmp/aletheia-migrate-*` directory per run.

## Files to touch

- `test/temp-dirs.mjs` (new): `tempDir(prefix)` registers a directory; `cleanupTempDirs()` removes them all.
- `test/temp-dirs.test.mjs` (new): proves the helper removes a non-empty directory and is idempotent.
- `test/migration-v3.test.mjs`: use the helper instead of a bare `mkdtempSync`.

## Acceptance criteria

- [x] `test/migration-v3.test.mjs` no longer leaves `/tmp/aletheia-migrate-*` directories behind.
- [x] The helper removes a non-empty directory and tolerates an already-missing one.
- [x] The migration tests still pass unchanged.
