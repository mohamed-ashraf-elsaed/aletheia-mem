## Steps

1. Use a pinned Bun base image.
2. Create a non-root user and a data volume.
3. Add `HEALTHCHECK` against `/healthz`.
4. Document the loopback bind.

Deviation, 2026-10-26: the compose file is `compose.yaml` (the current Compose name), not `docker-compose.yml`.
The compose default uses `network_mode: host` so the server keeps its loopback bind; the comment gives the
`127.0.0.1:37790:37790` alternative for Docker Desktop, which requires `ALETHEIA_HOST=0.0.0.0` and therefore
Hub login.
