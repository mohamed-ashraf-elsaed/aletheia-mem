`ALETHEIA_EXCLUDED_PROJECTS` is a comma-separated, case-insensitive list; `*` excludes everything. The hook, the CLI capture and `/v1/events` all skip an excluded project before any row exists and report `excluded_project`. `context({scope})` defaults to `current`; `all` includes other projects.

## Goal

Let a user exclude named projects from capture and choose current-project vs all-project context.

## Why

D1 F-C07, F-X04. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/config.mjs`
- `src/hub/capture.mjs`
- `src/hub/store.mjs`
- `test/excluded-projects.test.mjs`

## Steps

1. Parse `ALETHEIA_EXCLUDED_PROJECTS` as a comma-separated list.
2. Skip capture before writing an episode.
3. Add `scope: current|all` to `context`.

## Acceptance criteria

- [ ] An excluded project stores nothing and says why.
- [ ] `scope=all` includes other projects.
- [ ] `scope=current` is the default.
