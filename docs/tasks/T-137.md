# T-137: Add a Rules tab with the editor and suggested rules

Status: validated
Phase: P6
Depends on: T-134
Validated on: 2026-10-26
Evidence: see below.

## Goal

The Rules tab holds the existing rules editor and adds "suggested rules" from `rule_suggestions`, with Accept and
Dismiss. Nothing is applied without a click.

## Why

Rule suggestions were written by T-035 and listed only by `aletheia rules suggestions`; there was no page to act
on them. Part A of the `feat/one-ui` work order.

## Files to touch

- `public/tabs/rules.js` (new): rule list with turn off/on and edit, add form, suggested rules, dismissed
  suggestions with Restore, the sync panel and the import panel.
- The routes (`GET /api/hub/rule-suggestions`, `POST /api/hub/rule-suggestions/:id`) landed with T-134.

## Acceptance criteria

- [x] Rules can be listed, turned off and on (reversible), edited and added.
- [x] Suggestions are separate and only become rules after Accept.
- [x] Dismiss is reversible: dismissed suggestions are listed with Restore.
- [x] The existing sync and import panels are still reachable.
- [x] There is no Delete rule button in the UI; a rule is disabled instead.
