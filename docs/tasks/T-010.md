## Goal

Create the data dir `0700` and the database `0600`, and repair existing installs on open.

## Why

D1 F-O09. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/store.mjs`
- `src/config.mjs`
- `test/permissions.test.mjs`

## Steps

1. After creating the directory, `chmod 0700`.
2. After opening the database, `chmod 0600` the db, `-wal` and `-shm`.
3. Skip the repair with a warning when the platform does not support it.

## Acceptance criteria

- [ ] A new store has the expected modes.
- [ ] An existing 0644 store is repaired on open.
- [ ] A failure is logged, not swallowed.
