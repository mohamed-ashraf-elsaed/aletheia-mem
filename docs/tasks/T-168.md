# T-168: Roll up goals with request links, status and open asks

Status: validated
Phase: P6
Depends on: T-152
Validated on: 2026-10-26

## Goal

Extend the Work goals view to link requests to the owner's goals, give each goal Stalled / Moving / Nothing on it,
aggregate progress across the requests serving it, bucket requests that serve no goal, and split open asks into
"nothing is working on these" and "being worked on".

## Files to touch

- `src/hub/goals-rollup.mjs` (new)
- `src/hub/routes.mjs`
- `test/goals-rollup.test.mjs` (new)

## What changed

- `proposeGoalsRollup(store, {...})` computes goals and requests, links each request to the goal whose topic key and
  project match, and returns the goal list enriched with `status`, `aggregateProgress`, request counts and
  `whatCameOutOfIt` (the merged commit/PR/branch artifacts from its requests).
- Goal status is `Nothing on it` (no linked request), `Moving` (a request is Working, Waiting on you or Shipped), or
  `Stalled` (requests exist, all idle).
- `noGoal` holds requests that serve none of the goals; `openAsks` splits non-shipped goals into `beingWorked` and
  `nothingWorking`.
- `GET /v1/work/goals` now returns this roll-up (the original `goals`, `dismissedGoals` and `pinned` fields remain).

## Acceptance criteria

- [x] Goals are linked to requests with status and aggregate progress.
- [x] The no-goal bucket holds requests serving none of the goals.
- [x] Open asks split into nothing-working and being-worked-on.
- [x] An empty store says empty with no invented numbers.
