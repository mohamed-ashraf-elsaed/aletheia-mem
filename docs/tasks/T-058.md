Status: validated
Phase: P3
Depends on: none
Validated on: 2026-10-26
Evidence: see `## Evidence`

## Goal

`aletheia install claude-code` previews, backs up and applies MCP config, hooks and rules in one idempotent command.

## Why

D1 F-C02, F-I08, F-I09. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `bin/aletheia.mjs`
- `src/hub/install.mjs`
- `test/install-claude.test.mjs`

## Steps

1. Add `install <tool> [--write] [--dry-run]`.
2. Compose the MCP step, hook step and rules step from the registry.
3. Write a manifest of what was changed for uninstall.
4. Refuse an unknown tool with a list.

## Acceptance criteria

- [x] Dry run changes nothing and prints every step.
- [x] A second install changes nothing.
- [x] A backup exists for every modified file.
- [x] Unknown tools are refused with the list.
- [x] `aletheia uninstall <tool> --write` removes only the manifest's entries.
- [x] `aletheia doctor` checks the server, hooks, spool and last capture.
- [x] A settings file that is not valid JSON is refused, not overwritten.
