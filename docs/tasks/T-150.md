# T-150: Work tab polish (prompts, session-end, goals, 375px)

Status: validated
Phase: P6
Depends on: T-143, T-144
Validated on: 2026-10-26
Evidence: see the Validation section below.

## Goal

Polish the Work tab in four small ways: truncate long prompts with a plain-text expander, prefer a real
session-end event over the 5-minute heuristic, let goals read back-filled transcript user turns, and give
the 375 px layout no horizontal scroll with 40 px tap targets.

## Why

The owner requested a hardening pass over the Work tab. Long prompts overflowed the overview, a session
that had actually ended stayed "in progress" for up to 5 minutes, goals ignored transcript back-fill, and
the smallest phones had cramped tap targets.

## Files to touch

- `public/work-view.js`: `sessionCardView` truncates the prompt to ~200 chars, keeps `lastPromptFull` and
  `lastPromptTruncated`, and labels `stateDetail`.
- `public/tabs/work.js`: a plain-text "Show more"/"Show less" toggle (never `innerHTML`).
- `src/hub/store.mjs`: `session_end` table, `markSessionEnded`, `sessionEnd` (additive, idempotent).
- `src/hub/hooks/{shared,run,claude-code,codex,cursor,gemini-cli,command-code}.mjs`: record a real
  session-end event (and flush it from the spool).
- `src/hub/work.mjs`: prefer the recorded end event; keep the 5-minute heuristic as fallback.
- `src/hub/goals.mjs`: read `episodes` user turns, dedupe by text hash within the same session.
- `public/one-ui.css`: 375 px media query and 40 px tap targets.
- `docs/manual-test.md`: the 375 px and tap-target manual step.
- Tests: `test/work.test.mjs`, `test/work-views.test.mjs`, `test/work-goals.test.mjs`, `test/one-ui.test.mjs`,
  `test/e2e-more-hosts.test.mjs` (timeout for the heavy subprocess test).

## Steps

1. Write the DOM-free and store-level assertions first.
2. Implement each of the four changes.

## Acceptance criteria

- [x] Long prompts truncate to ~200 chars in the card; "show more" expands; text is never HTML-injected.
- [x] A recorded session-end event finishes a session and is labelled; the heuristic is the fallback label.
- [x] Back-filled user episodes form goals and dedupe against hook prompts in the same session.
- [x] The stylesheet opts out of horizontal scroll and sets 40 px tap targets at 375 px.
