## Goal

Traverse entity links from seed results and add neighbours as a fourth ranked list fused with RRF.

## Why

D3 E12; D1 F-S08. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/graph.mjs`
- `src/hub/store.mjs`
- `bench/locomo-retrieval.mjs`
- `test/graph.test.mjs`

## Steps

1. Start from top lexical/dense results.
2. Walk 1-2 hops on entity links with a bounded fan-out.
3. Fuse as a fourth list.
4. Report graph rank in the trace.

## Acceptance criteria

- [ ] Multi-hop Recall@5 rises >= 5 points or the result is negative.
- [ ] The walk is bounded and times out.
- [ ] No graph rows cross projects.
