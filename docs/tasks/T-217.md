# T-217: Put Alerts and Team in the Tools tab on the shared components

Status: validated
Phase: P6
Depends on: T-211, T-207
Validated on: 2026-10-26

## Goal

The team-mode and alert-rule APIs merged from the hardening branch (T-112, T-114) had unwired tab modules. Give them real pages in Tools: alert rules with Send a test and a confirmed Remove, a server-paged delivery feed, and teams with shared projects, members, a board, a brief and search.

## Files to touch

- `public/tabs/tools-team.js`
- `public/tabs/tools.js`
- `public/ui-core.js`
- `src/hub/routes.mjs`
- `test/ui-tools-team.test.mjs`

## What changed

- The hardening work merged into main brought Team (T-112) and Alerts (T-114) as tab modules (`public/tabs/team.js`, `public/tabs/alerts.js`) that nothing loads, because the shell had not been given a place for them. They are left as they are. Their features now have pages in the Tools tab on the shared components.
- `public/tabs/tools-team.js`: Alerts (rule cards with target, signing and private flags, Send a test with counts, Remove behind a confirm that says it cannot be undone, an Add dialog that checks for a destination first, Deliver due now, a server-paged delivery feed) and Team (teams with role, the chosen team and project kept in the address, a stat strip, shared projects and Share a project, a viewer sees it disabled, members table, board, brief as safe Markdown, search over shared memory).
- `public/ui-core.js`: Tools gains the pages Alerts and Team, so the palette and the shortcuts find them.
- `src/hub/routes.mjs`: `/api/hub/alerts/feed` takes `limit` and `offset` and answers `total` and `hasMore` (the newest 500 deliveries are pageable).
- `test/ui-tools-team.test.mjs`: 12 tests. `test/ui-a11y.test.mjs` now audits both pages, which caught a team name without a text direction. `test/ui-contract.test.mjs` ignores routes named in comments.
- Checked in Chromium: empty Alerts, adding a file rule, empty Team, creating a team; no console errors.

## Acceptance criteria

- [x] Alerts and Team appear as pages of the Tools tab with the same states, paging and dialogs as the other pages.
- [x] The alert delivery feed pages on the server (limit, offset, total).
- [x] Removing a rule asks first; a viewer cannot share a project.
