## Goal

Fail CI when a required runtime dependency is added without a documented reason, or when a dependency has a copyleft licence that conflicts with Apache-2.0 distribution.

## Why

D1 F-P11; docs/15 NFR-6. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `scripts/audit-deps.mjs`
- `package.json`
- `docs/dependencies.md`

## Steps

1. Read package.json and the lockfile.
2. Assert the required dependency list is empty or matches an allowlist with a reason.
3. Print licences for dev dependencies and flag copyleft.

## Acceptance criteria

- [ ] Zero required dependencies passes.
- [ ] A new required dependency fails unless allowlisted.
- [ ] The output names the licence.

## Validation command

```bash
bun scripts/audit-deps.mjs
```

Expected: deps ok: 0 required, <n> dev
