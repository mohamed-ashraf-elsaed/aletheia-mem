## Deviations

- 2026-10-26: Bedrock has no preset. Its request shape is not OpenAI-compatible, and no AWS SDK is allowed
  (zero npm dependencies). A Bedrock gateway that exposes the OpenAI shape works through `anthropic-compatible`
  or `local`.
- 2026-10-26: `anthropic-compatible` has no default URL. Anthropic publishes no OpenAI-shaped chat endpoint that
  this repo can verify; the preset requires `ALETHEIA_ANTHROPIC_BASE_URL` and fails with that name if unset. This is
  recorded in `docs/tasks/unverified.md`.
- 2026-10-26: the chain lives in `ALETHEIA_PROVIDERS` (`ollama,openrouter,openai`), not a new config file. A single
  provider keeps using `ALETHEIA_PROVIDER`.
