The worker writes `fact_vectors` when an embedder is supplied; `aletheia embed` backfills facts and memories; `aletheia search --semantic`
uses dense channels and `--explain` prints them. Without the optional runtime both commands fall back to keyword channels, and
`/v1/search` states that it answered from keyword channels only.

## Goal

Automatic fact embeddings when the optional runtime is present, a keyword fallback when it is not, RRF over facts and
episodes, and a channel report on every search.

## Why

[26-memory-pipeline.md](../26-memory-pipeline.md) section 26.7 lists "automatic fact embeddings" as not built; the
design is in [23](../23-memory-building.md) section 23.1 (keys indexed for retrieval).

- [x] Every result carries `channels` describing what ran.
