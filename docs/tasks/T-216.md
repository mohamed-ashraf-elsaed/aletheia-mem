## What changed

- `scripts/seed-demo.mjs`: fills a folder with clearly fake data (projects `demo-*`, tool `demo-seed`, Arabic text, a 200-character token, Markdown with code, a list and a table, pinned rows, review items, suggestions, dismissed rows, audit rows). It has no default folder, refuses `~/.aletheia`, `~/.work-view-local`, `~/.claude-mem` and `~/.claude`, and refuses a database that holds rows it did not seed. The same seed gives the same text. `test/seed-demo.test.mjs`: 9 tests.
- `scripts/measure-api.mjs`: times the list routes against a running server (median and p95).
- `?demo=1` shows a banner saying the data is made up, and sets `data-demo` on the page.
- `test/ui-contract.test.mjs`: reads every API path the UI scripts name (about 40), starts a real server and checks each is a real route (an unknown path answers `{"error":"Not found."}`, a real route answers with its own reason), checks that every module the shell imports is served, and checks the page's security header.
- `src/server.mjs`: the app page is served with a strict Content-Security-Policy (`default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'self'`). No console violation on 13 routes plus a dialog, the palette, a popover and the theme switch.
- Layout shift fixed: the status strip and brand mark now reserve their height, and the stat skeleton matches a real tile. Memory page 0.107 before, 0.012 after.
- `docs/06-frontend.md` rewritten for the app, with the paging table, shortcuts and security; the old viewer notes are kept under 6.9. `docs/ui-design.md` gains brand details, screenshots, the accessibility audit and the measured performance with machine and date. `docs/manual-test.md` records the browser pass and what was not run. 12 screenshots (WebP, 420 KB) in `docs/screenshots/`, all of the real running app on demo data with the demo banner visible.
- Measured on an Intel i7-8850H, Chromium 156, 5,000 seeded memories, 2026-10-26 UTC: shell first paint median 92 ms (5 of 7 loads under 100 ms, max 104 ms: NOT all under 100 ms); scrolling 100 cards median frame 13.3 ms, none over 33 ms; Next page 21 to 30 ms; list routes 0.3 to 10 ms median, `/v1/work` 65 ms.
