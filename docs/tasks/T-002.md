## Goal

## Why

## Steps

1. Run both commands with a timeout and capture stdout/stderr and exit codes.
2. Write a dated report with the exact commands and full output in fenced blocks.
3. Refuse to write when either command fails, unless `--allow-fail` is passed.

## Acceptance criteria

- [ ] The report contains both commands and their real output.
- [ ] A failing command is recorded with its exit code.
- [ ] The script is idempotent.
