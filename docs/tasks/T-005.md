## Goal

Pin the request and response shape of every route in the README's interface table.

## Why

D1 F-I05. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,

## Files to touch

- `test/routes-contract.test.mjs`

## Steps

1. Start the server on an ephemeral port with a temp data dir.
2. For each route, assert status, content type and required keys.
3. Assert the optional bearer key is enforced on `/v1/*`.

## Acceptance criteria

- [x] Every documented route has at least one test.
- [x] A removed key fails the test.
- [x] A wrong method returns 404 or 405, not 200.
