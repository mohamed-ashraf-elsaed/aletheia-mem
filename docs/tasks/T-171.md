# T-171: Add rule strength and evidence (times seen, dated quotes)

## Goal

Every rule suggestion stores how often it was seen, its latest date and dated quotes, and its strength is Strong /
Steady / Light from documented thresholds. "N more quotes" is returned for long quote lists.

## Files to touch

- `src/hub/store.mjs`: `times_seen`, `latest_at_epoch` columns and `rule_suggestion_quotes` table (additive).
- `src/hub/rule-suggest.mjs`
- `src/hub/routes.mjs`
- `test/rule-strength.test.mjs` (new)

## What changed

- `ruleStrength(timesSeen)` documents the thresholds: Strong at 5+, Steady at 3-4, Light at 1-2.
- `suggestRules` groups corrections by (project, rule text), counts occurrences, records the latest date, and inserts
  dated quotes with source and session ids. A second run updates the counts and adds no duplicate quotes.
- `listSuggestions` returns `timesSeen`, `strength`, `latestAt`, `quotes` and `moreQuotes` for each suggestion.
- `GET /api/hub/rule-suggestions` now exposes those fields alongside the existing ones.

## Acceptance criteria

- [x] Strength thresholds are Strong at 5+, Steady at 3-4, Light at 1-2.
- [x] `suggestRules` stores times seen, latest date and dated quotes.
- [x] A second run does not duplicate quotes.
- [x] A fresh database has the strength columns and the quotes table.
