## What changed

- `public/index.html`: new shell markup (skip link, brand, nav, project, search with a results list, theme slot, status strip, live announcer). No inline script, style or handler.
- `public/one-ui.js`: tabs with a sliding indicator, hash routes with pages inside tabs (`routeOf`), a page or filter change in the hash does not rebuild the view, project saved in localStorage, theme control, search, shortcuts, palette.
- `public/ui-theme.js`, `public/ui-theme-init.js`: Auto, Dark, Light saved under `aletheia.theme`; the early script avoids a flash.
- `public/ui-search.js`: header search, debounced 220 ms, from 2 characters, older answers dropped, arrow keys, Esc, Enter opens the results page.
- `public/ui-keys.js`: Ctrl+K palette (pages, sub pages, theme, refresh, shortcuts, memory and session hits from the server), `/`, `g` then `w`, `m`, `r`, `t`, `[` and `]` for the visible pager, `?` sheet. Nothing fires while typing in a field or while a dialog is open.
- `public/ui-detail.js`: drawer for one memory or fact.
- `public/ui-status.js`: first version with one server indicator (T-206 replaces it).
- `public/one-ui.css`: header, status strip, page layout, palette; older Work-tab classes moved onto the new tokens.
- `scripts/seed-demo.mjs`: clearly fake demo data into a folder you name (no default). Used for the browser checks.
- Checked in Chromium at 1280, 768 and 375 px, light and dark: no horizontal scroll, theme persists across reload, chords and palette work.
