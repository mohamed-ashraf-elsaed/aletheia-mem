## Acceptance criteria

- [x] The TOML block re-plans byte-identically (idempotent round trip).
- [x] An existing `[mcp_servers]` table is preserved.
- [x] A malformed file is refused, not overwritten.
- [x] Hooks use the documented nested JSON shape in `~/.codex/hooks.json`.

## Verification

- Hooks: `https://developers.openai.com/codex/hooks` fetched 2026-10-26. Confirms
  `~/.codex/hooks.json` or inline `[hooks]`, the nested shape
  `{hooks: {Event: [{matcher?, hooks: [{type, command, timeout}]}]}}`, and the events `SessionStart`,
  `UserPromptSubmit`, `PostToolUse`, `Stop`, `SessionEnd`, with `prompt`, `tool_name`, `tool_input`,
  `tool_response`, `last_assistant_message` and the common `session_id`/`cwd` fields.
- MCP: `https://developers.openai.com/codex/config-reference` and `/codex/mcp` fetched 2026-10-26.
  Confirms `[mcp_servers.<name>] command = ...; args = [...]`.
- Rules: no global Codex rules path was verified. The installer writes no global rules file and says so;
  `aletheia rules sync` writes the project `AGENTS.md` (T-070).
- Codex 0.130.0 is installed on this machine, but no real Codex hook ran. This is `from-docs-only`.

## Limitation

There is no TOML parser without a new dependency. The guard rejects a JSON-shaped file, duplicate
`[mcp_servers.aletheia]` tables and unbalanced quotes; it is not a full TOML parser. Full parsing is listed in
[docs/tasks/unverified.md](unverified.md).
