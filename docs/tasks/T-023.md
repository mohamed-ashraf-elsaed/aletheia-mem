## Goal

Every fact and observation resolves to the episodes that produced it, and every retrieval result can show that chain.

## Why

D4 section 23.3.4; D1 FR-M1. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/store.mjs`
- `test/provenance.test.mjs`

## Steps

1. Add foreign keys where missing.
2. Add `memory_links` rows for mentions and derivation.
3. Add a `provenance(id)` helper returning episodes and source refs.

## Acceptance criteria

- [ ] A fact without an episode is impossible.
- [ ] `provenance` returns the original turn text.
- [ ] Deleting an episode is refused while a fact references it.
