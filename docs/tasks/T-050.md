## Goal

Cache retrieval results by normalised query and store version, with correct invalidation on writes.

## Why

D3 E14. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/cache.mjs`
- `bench/scale.mjs`
- `test/cache.test.mjs`

## Steps

1. Key on normalised query + filters + store revision.
2. Bound the cache size.
3. Invalidate on any write that changes the store revision.
4. Measure hit rate on a replayed session.

## Acceptance criteria

- [ ] A write never returns a stale result.
- [ ] Hit rate >= 30% on the replay, or the cache is removed.
- [ ] p95 drops >= 30% when warm.
