Measured Spearman 0.645 on a **synthetic** 200-item rank, not the 200 human-ranked observations in D4 §23.9. The
formula is `0.35*type + 0.25*recency + 0.20*reinforcement + 0.10*provenance + 0.10*user`; `recency` is an exponential
decay with a 90-day half-life; `reinforcement` is currently the number of linked facts capped at 5, because
re-confirmation counting is not built. `aletheia importance recompute` writes the score and the JSON components.
