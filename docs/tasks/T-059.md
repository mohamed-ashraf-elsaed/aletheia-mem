# T-059: Add Claude Code hooks and automatic context

Status: validated
Phase: P3
Depends on: T-058
Validated on: 2026-10-26
Evidence: see `## Evidence`

## Goal

Capture SessionStart, UserPromptSubmit, PostToolUse and Stop, and inject context once per session and after compaction.

## Why

D1 F-C01, F-X01, F-C12. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `src/hub/hooks/claude-code.mjs`
- `test/claude-hooks.test.mjs`

Also added: `src/hub/hooks/shared.mjs`, `src/hub/hooks/run.mjs`, `src/hub/redact.mjs`.

## Steps

1. Map each hook payload to `capture`.
2. On SessionStart print `store.context` to stdout.
3. On UserPromptSubmit store the prompt; on PostToolUse store the event; on Stop enqueue compression.
4. Detect compaction and re-inject.

## Acceptance criteria

- [x] A simulated session produces prompts and events.
- [x] SessionStart output contains the context block.
- [x] A hook returns in < 100 ms without a model call.
- [x] `resume` is silent; `compact` and `clear` re-inject.
- [x] Repeated events are deduped.
- [x] Broken input, an unknown event and an unknown tool all exit 0.
- [x] A store that cannot open spools the redacted item; the next run flushes it.
- [x] Recalled text is wrapped as untrusted data.
