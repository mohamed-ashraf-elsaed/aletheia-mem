## Goal

The default Work tab shows this hub's own data: a header strip, a "Now" column, a "Needs you" column, recent
memory and (in T-144) goals. It refreshes every 10 seconds only while visible.

## Files to touch

- `public/work-view.js`
- `public/tabs/work.js`
- `public/one-ui.js`
- `public/index.html`
- `public/one-ui.css`
- `test/work-views.test.mjs`
- `test/one-ui.test.mjs`

## What changed

- `public/index.html` mounts `<div id="ui-work">`; the iframe is gone from the default tab.
- `public/one-ui.js` loads `./tabs/work.js` like the other tabs. A `#/work/session/<id>` hash still resolves to Work
  and is handled by the Work module.
- `public/work-view.js` is DOM-free: header, session cards, needs items, fact lines, goals and session detail. All
  strings come from the API response; nothing is invented.
- `public/tabs/work.js` renders the overview, accepts/rejects review items, accepts/dismisses rule suggestions,
  restores dismissed rows, and pins/dismisses goals (T-144). It refreshes every 10 s, skips the fetch while
  `document.visibilityState !== "visible"`, and stops when the route leaves Work.
- An empty response shows the command `aletheia install claude-code --write`, not a fake session.
- The old viewer is still served at `/work-view/work.html`; the default page does not reference it.

## Acceptance criteria

- [x] Header strip: health, last capture, queue depth, mode.
- [x] "Now" lists in-progress and recently finished sessions, newest first, with counts, last prompt, summary,
      source facts and a session link.
- [x] "Needs you" lists review items, rule suggestions and dismissals in the last 24 h with actions.
- [x] "Recent memory" lists current facts with source and importance.
- [x] Live refresh is 10 s, visible only; hidden tabs do not fetch.
- [x] The empty state gives an install command and never fake data.
- [x] `/` no longer contains an iframe or a reference to `work.html`.
