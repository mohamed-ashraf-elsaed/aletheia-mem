## Goal

Add `.claude-plugin/`, `.codex-plugin/` and `.qoder-plugin/` manifests that point at the MCP server and hooks.

## Why

D1 F-I10, F-I11, F-I12, F-P22. See [20-claude-mem-feature-matrix.md](../20-claude-mem-feature-matrix.md) and, where relevant,
[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Files to touch

- `.claude-plugin/plugin.json` (new): metadata, inline MCP server, inline `SessionStart`/`Stop` hooks.
- `.codex-plugin/plugin.json` (new): metadata and inline `SessionStart`/`Stop` hooks.
- `.qoder-plugin/plugin.json` (new): metadata only.
- `gemini-extension.json` (new): metadata and an MCP server using `${extensionPath}`.
- `test/manifests.test.mjs` (new): the validation test.
- `docs/25-installers.md`, `docs/tasks/research-log.md`, `docs/tasks/unverified.md`: sources, limits and the
  from-docs-only label.

## Steps

1. Follow each host's manifest schema from its documentation.
2. Reference the same bin entry and hook scripts.
3. Add a test that parses every manifest.

Deviations, 2026-10-26:

- **Codex** is written as the `.codex-plugin/plugin.json` compatibility manifest the official page names. The
  page does not publish a field table for that manifest or a local `.mcp.json` server shape, so the file carries
  only `name`, `version`, `description` and `hooks` (the field the page says may be declared there). The MCP
  entry is omitted instead of guessed.
- **Qoder** gets metadata only. The official page documents `mcpServers` and `hooks` fields but no plugin-root
  path variable, so a relative command would resolve against an unknown working directory.
- **Gemini CLI** was added because its official reference documents a full extension manifest with
  `${extensionPath}`, so the MCP server can be pointed at safely.
- Every manifest says `from-docs-only`; no host was opened. The gaps are in `docs/tasks/unverified.md` rows 43-46.

## Acceptance criteria

- [x] Paths resolve inside the package.
- [x] No manifest claims a hook that does not exist.
