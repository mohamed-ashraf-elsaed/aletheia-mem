## Goal

Every empty result says why it is empty (no rows, no query terms, filter excluded all) instead of returning a bare empty list.

## Steps

1. Return `{items: [], reason: 'no_terms'|'no_rows'|'filtered'}` from the ranked path.
2. Include the reason in the MCP text response.
3. Keep HTTP responses backward compatible by adding a `reason` field only.

- [ ] A query with terms but no rows says `no_rows`.
