Store valid time and record time separately, with `valid_to` as the only way a fact stops being current.

[22-improve-the-numbers.md](../22-improve-the-numbers.md) or [23-memory-building.md](../23-memory-building.md).

## Steps

1. Add `valid_from_epoch`, `valid_to_epoch`, `recorded_at_epoch`.
2. Migrate existing facts with `valid_from = created_at` and `recorded_at = created_at`.
3. Add indexes for the valid-time query.

## Acceptance criteria

- [ ] A fact with `valid_to` is excluded from current results.
- [ ] The same fact is returned by an `as_of` query inside its range.
- [ ] `recorded_at` never changes on update.
